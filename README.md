# 25 bröllopsfotografer

25 fristående demosajter för påhittade bröllopsfotografer, alla i olika stil, byggda på bilder och film från Lena Hammar.

- `index.html` – översikt
- `sites/NN-namn/index.html` – varje sajt (fristående HTML/CSS/JS)
- `media/` – bilder och `hero.mp4`

Kör: `npm i && npm run dev` (eller valfri statisk server från repots rot).
